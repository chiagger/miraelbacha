# Mira El Bacha

La repository contiene il sito pubblico nella root e il pannello di gestione indipendente in `apps/admin`.

- Sito: `npm ci` e `npm run dev` → http://localhost:3000.
- Pannello: `npm --prefix apps/admin ci` e `npm run dev:admin` → http://localhost:3001.
- [Configurazione Firebase, funzionalità e deploy del pannello](apps/admin/README.md).

Il sito mantiene i contenuti iniziali finché non viene impostata `NEXT_PUBLIC_CONTENT_API_URL`; dopo il collegamento, CV e portfolio si aggiornano dai contenuti salvati nel pannello.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
